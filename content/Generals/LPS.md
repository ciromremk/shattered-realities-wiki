# LPS (Last Player Standing)

> Un modo aparte, no es una variante de los otros: cuando queda **1 superviviente**, la partida cambia de reglas.

Volver: [[index|Shattered Realities]]

## Qué es
LPS es el modo en el que **solo queda un superviviente** y la ronda se decide en un duelo de supervivencia. Es el modo más tenso del juego y el único donde el clima entre supervivientes cambia por completo: ya no hay equipo.

## Qué cambia con respecto a los demás modos
| | Mapas normales | **LPS** |
| - | - | - |
| **Objetivo** | Completar tareas / sobrevivir al timer | Sobrevivir al duel |
| **Tareas y salidas** | Sí | **No**: el último superviviente ya no puede hacer nada de eso, así que se ignoran |
| **Timer** | Según el mapa | **Puro**: la partida es un timer de supervivencia |
| **Fin** | Todos escapan o caen | Timer a 0 → gana el último superviviente; si cae → gana el killer |

## Reglas especiales
- Da igual que el killer sea boss o no: el modo es el mismo.
- **No Cowards está desactivado**: el medidor de inactividad no corre en LPS (ver [[No Cowards]]).
- **Timer Block no aplica**: las ults que suman tiempo al timer o bloquean salidas no funcionan en LPS.
- **Habilidades con variante LPS**: algunos supervivientes cambian una habilidad en este modo (ej. [[Barry The Hedgehog|Barry]] con *Keep Up* y *Chaos Blast*).
