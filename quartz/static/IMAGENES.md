# Imágenes de la wiki

Quartz lee de esta carpeta (`wiki/quartz/static/`) todo lo que salga como imagen o icono.

## Qué poner aquí
| Archivo | Para qué sirve | Tamaño recomendado |
| ------- | -------------- | ------------------- |
| `favicon.png` | El ícono de la pestaña del navegador | 512×512 o 256×256 px |
| `og-image.png` | La imagen que se ve al compartir el link (Discord, Twitter, etc.) | 1200×630 px |

## Notas
- Formato: **PNG** (JPG también sirve para la imagen de compartir, pero PNG conserva mejor el texto).
- Si el archivo no existe, Quartz genera un favicon/og-image por defecto — no se rompe nada.
- Las imágenes que pongas aquí se publican en la wiki; **no subas nada que no quieras público**.
- Cualquier otra imagen (logos, capturas de personajes) también puedes ponerla aquí y usarla desde las notas así:
  `![[nombre.png]]`
